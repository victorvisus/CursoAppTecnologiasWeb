Formularios HTML
-para que sirven
-estructura básica de la tag form
---'action': URL donde se envían los datos.
---'method': Método HTTP de envío (GET o POST).
---'name': Nombre del formulario (útil para JavaScript).
-metodo get
-metodo post
-otros atributos para form
--'enctype': Tipo de codificación (obligatorio para subir archivos). Valores:
--'application/x-www-form-urlencoded' (predeterminado)
--'multipart/form-data' (para archivos)
--'text/plain' (texto sin formato)
--'target': Dónde mostrar la respuesta. Valores:
--'_self', '_blank', '_parent', '_top'
--'autocomplete': permitir autocompletado.
--'novalidate': Desactivar validación nativa.
-Campos de entrada (Inputs) en formularios web
-Elemento INPUT básico
--Atributos fundamentales:
--Todos los types y sus usos
----Texto
--------'type="text"': Campo de texto básico de una sola línea.
--------'type="password"': Campo para contraseñas (oculta caracteres).
--------'type="email"': Campo para correos electrónicos.
--------'type="tel"': Campo para números telefónicos.
--------'type="url"': Campo para direcciones web.
----Numéricos y temporales
--------'type="number"': Campo para valores numéricos.
--------'type="range"': Control deslizante para seleccionar un valor.
--------'type="date"': Selector de fecha.
--------'type="time"': Para seleccionar hora.
--------'type="datetime-local"': Fecha y hora.
--------'type="month"': Selección de mes y año.
--------'type="week"': Selección de semana del año.
----Selección
--------'type="checkbox"': Casillas de verificación (selección múltiple).
--------'type="radio"': Botones de opción (selección única).
----Especiales
--------'type="color"': Seletor de color.
--------'type="file"': Carga de archivos. Para cargar archivos tiene que haber 'enctype="multipart/form-data"', con 'accept limitas los tipos de archivo con 'multiple' permite varios archivos.
--------'type="hidden"': Campo oculto, no visible al usuario (por ejemplo, para mandar info por defecto).
--------'type="search"': Campo de búsqueda.
----botones:
--------'type="submit"': Envía el formulario.
--------'type="reset"': Restablece los valores iniciales.
--------'type="button"': Botón genérico (para JavaScript).
